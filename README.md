##  Условие задачи (Вариант 29,номер по списку группы)
Составить программу, которая проверяет принадлежит ли заданная пользователем точка с
координатами (х, у) заданным закрашенным (заштрихованным) областям, показанным на рисунках
в табл., и выводит на экран сообщение.

## Контрольный пример
Точка принадлежит заштрихованной области, если одновременно выполняются три условия:

$$
\begin{cases}
y \geq 0 \\
x^2 + y^2 \leq 36 \\
\neg(x \geq 0 \land x^2 + y^2 \leq 9)
\end{cases}
$$

На данном изображении я наглядно показала, что зеленая точка c координатой (4;1) принадлежит заштрихованной области, а красная точка с координатой (5;6) не принадлежит заштрихованной области.

## 1. Алгоритм и блок-схема
# Алгоритм

## Входные данные
Координаты точки `x` и `y`.

## Выходные данные
Сообщение о принадлежности точки заштрихованной области.

---

## Ход решения

**1.** Начало.

**2.** Объявить переменные `x` и `y` типа `double`.

**3.** Запросить у пользователя координаты точки.

**4.** Считать значения `x` и `y`.

**5.** Проверить, лежит ли точка в верхней полуплоскости:
> если `y < 0` — точка **не принадлежит** области, перейти к шагу 9.

**6.** Проверить, лежит ли точка внутри круга радиуса 6:
> если `x² + y² > 36` — точка **не принадлежит** области, перейти к шагу 9.

**7.** Проверить, не попала ли точка в правую половину малого круга радиуса 3:
> если `x ≥ 0` и `x² + y² ≤ 9` — точка **не принадлежит** области, перейти к шагу 9.

**8.** Точка **принадлежит** заштрихованной области.

**9.** Вывести результат.

**10.** Конец.

## 2. Реализация программы
```c
#include <stdio.h>
#include <locale.h>
int main() {
    setlocale(LC_CTYPE, "RUS");
    double x, y;
    printf("Введите координаты точки x и y через пробел: ");
    scanf("%lf %lf", &x, &y);
    if (y >= 0 && (x * x + y * y <= 36.0) && !(x >= 0 && (x * x + y * y <= 9.0))) {
        printf("Точка (%.2f, %.2f) ПРИНАДЛЕЖИТ заштрихованной области.\n", x, y);
    }
    else {
        printf("Точка (%.2f, %.2f) НЕ ПРИНАДЛЕЖИТ заштрихованной области.\n", x, y);
    }
    return 0;
}
```
